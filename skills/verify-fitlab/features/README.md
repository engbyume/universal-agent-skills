# FitLab Feature Map

Use the feature files to choose a headed, synthetic-data user flow. Run all flows at `http://localhost:5173/` so test data stays separate from the user's default local profile.

| Feature | Coverage |
| --- | --- |
| [Local workspace](local-workspace.md) | Profile setup, privacy controls, data import and export, profile deletion |
| [Closet](closet.md) | Item creation, ownership, search, editing, and local photos |
| [Person and fit references](person-fit-references.md) | Measurements, unit conversion, and face, body, or pose references |
| [Outfit planner](outfit-planner.md) | Outfit layers, planning modes, layout preview, and saved looks |

For every run, record the action and visible result. Preserve one synthetic screenshot and accessibility snapshot in `fitlab/.verification/`.
